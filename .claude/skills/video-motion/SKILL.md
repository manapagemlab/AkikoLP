# 動画・モーション制作スキル

動画やアニメーションを作るときは、「何を伝えるか」を先に決めてから「どう動かすか」を選ぶ。動きから決めない。

## 参照する資料

| 資料 | 場所 | 使う場面 |
|---|---|---|
| 企画ナレッジ | `docs/motion/animation-planning-crevo.md` | 目的・尺・訴求の数・構成・手法を決める |
| 表現ライブラリ 目次 | `docs/motion/index.md` | カテゴリー別に動きの候補を探す |
| 表現ライブラリ 本文（284個） | `docs/motion/hyougen-library-284.md` | 選んだ表現の設定値（秒数・イージング・拡大率など）を確認する |
| MotionLibrary（あっこさん自作のChrome拡張） | 未収録 | 収録されるまでは、あっこさんに見本の名前やスクショをもらう |

## 手順

### 1. 企画を決める（企画ナレッジの「企画チェックリスト」を使う）

次を決めてから先に進む。決まっていなければ、あっこさんに確認する。

- 目的は1つ：認知・理解・申込・ブランディングのどれか
- 配信先と尺：リール、広告、note埋め込み、LPなど
- 訴求の数：6秒なら1つ、30秒なら「全体像と手順」まで
- 冒頭5秒で「何の話か」を言い切る一文
- 最後に出す名前と行動（LINE登録、診断など）

構成は、説明動画なら「課題 → 解決策 → 手順 → 不安の解消」を基本にする。

### 2. 手法を選ぶ

個人制作では、モーショングラフィックス、タイポグラフィ、インフォグラフィックを優先する。3Dとフレームバイフレームは、制作コストが高いので最初の候補から外す。

### 3. 動きを選ぶ（表現ライブラリ）

1. `docs/motion/index.md` で、場面に合うカテゴリーから候補を2〜3個選ぶ
   - 文字を出す → テロップ、文字デザイン、フォント
   - 物や商品を見せる → 物の動き、光・ライト、3D
   - キャラクター（のりこおばちゃんなど）→ キャラの動き
   - 画面の切り替え・寄り引き → カメラ、奥行き・近影
   - 画面の構成 → レイアウト
2. 本文で番号を検索し（例：`## 5.`）、「ページに書いてある設定」の数値をそのまま使う
3. 1つの場面で主役にする動きは1つだけ。全部を同時に動かさない

### 4. 作る

- 無料でできる方法を先に提案する：Canva（無料プランあり）、HTML/CSSのアニメーションを録画またはffmpegで書き出す方法など
- HTMLで実装する場合は `prefers-reduced-motion`（動きを減らす設定）に対応する
- LPに入れる場合は、表示の重さに注意し、動きは要所だけに絞る

### 5. 出す前に確認する

- 企画チェックリストを全部満たしているか
- 使った表現の番号と名前を、あっこさんに一覧で伝える（あとで調整しやすくするため）

## 守ること

- 資料に書いていない表現や数値を、推測で「ライブラリにある」と言わない
- 企画ナレッジの元記事には成果の数字（再生数・CVRなど）がない。「成功が証明された手法」として説明しない。【転用メモ】の箇所はClaudeの解釈として扱う
- 表現ライブラリはサイトが更新される可能性がある。あっこさんが「更新した」と言ったら、書き出し直してもらって `docs/motion/` を差し替える
