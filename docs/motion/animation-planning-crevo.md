# アニメーション動画 企画ナレッジ

> 注意：元記事は制作会社が自社の実績を紹介するものです。「成功事例」とありますが、再生数やCVR（成約率）などの成果データは載っていません。このファイルでは、成果が証明された手法としてではなく、作例と定石として扱います。
> 「【転用メモ】」と書いた箇所は、元記事の内容ではなくClaudeが加えた解釈です。

---

## 1. 判断の起点：いつアニメを選ぶか

アニメが向いているのは、次のどれかに当てはまるときです。

- 伝えたいものが、形のないもの（サービス、仕組み、安心感、コンセプト）
- データや手順を、直感的に理解してもらいたい
- 撮影の手間やコスト（場所・出演者・機材）を避けたい
- 公開後に差し替えや修正が出そう（数字の更新、表現の調整など）
- 多言語に展開したい（ナレーションを差し替えるだけで済む）

実物の質感を見せたい有形の商品なら、実写のほうが効果的だと元記事にも書かれています。実写とアニメを組み合わせる方法もあります。

【転用メモ】AmeCan.の商品（WISC解説、観察ノート、アプリ）は、ほとんどが無形の「考え方」や「手順」です。アニメ表現との相性は高いと考えられます。

## 2. 手法の種類（何を動かすか）

| 手法 | 中身 | 向いている用途 |
|---|---|---|
| インフォグラフィック | 図・表・グラフで情報を整理して見せる | 数字、比較、手順の説明 |
| モーショングラフィックス | 写真・文字・図形など静止した素材に動きをつける | サービス紹介、ロゴ、オープニング。低予算・短納期向き |
| タイポグラフィ | 文字そのものを動かす | 一言のメッセージを強く打ち出す、SNS広告 |
| 3D | 立体的なCGで作る | 形・サイズ感・設置したときのイメージを伝える |
| 2.5D | 2Dと3Dの中間の表現 | ※元記事は3Dの説明文を誤って転記しているため、定義は未確認 |
| ホワイトボード | 白い背景に手描きしていく過程を見せる | 解説・教育。色に気を取られず内容に集中してもらえる |
| イラストアニメ（フレームバイフレーム） | 1コマずつ描いて動かす | 世界観やブランドイメージを作る。作業量は膨大 |

演出として、次の2つがよく使われます。

- キャラクター：「この会社といえばこのキャラ」と覚えてもらいやすくなる。ターゲット自身をキャラにすると、見る人が自分ごととして受け取りやすい
- インフォグラフィック：冒頭で数字を見せて課題に気づかせ、そのあとにサービスの説明へ入る流れが定番

## 3. 尺と費用の目安（外注した場合、Crevoの実績値）

| 手法 | 尺 | 費用レンジ |
|---|---|---|
| フレームバイフレーム | 15〜30秒 | 〜49万円 |
| モーショングラフィックス | 60〜120秒 | 50〜99万円 |
| キャラクターアニメ | 15〜30秒 | 50〜99万円 |
| インフォグラフィック | 60〜120秒 | 50〜99万円 |
| 3DCG | 15秒以内 | 100〜299万円 |

【転用メモ】個人で作る場合は、Canva（無料プランあり）のアニメーション機能や、HTMLスライドとffmpegを組み合わせる方法で、モーショングラフィックス、タイポグラフィ、インフォグラフィックの大半を0円で作れます。3Dとフレームバイフレームは個人の制作コストが高いので、最初の選択肢からは外すのが現実的です。

## 4. 事例から抜き出した定石

| 事例 | 目的 | 尺 | 使える型 |
|---|---|---|---|
| 宅本便（ブックオフ） | YouTube広告 | 30〜60秒 | スキップされる前の5秒で、サービスの全体像を一文で言い切る。手順は4ステップに分けて見せる。困っている状態からスッキリした状態へ変わるストーリー |
| engage（エン・ジャパン） | 6秒のバンパー広告 | 〜15秒 | 訴求を1点に絞る（「無料で作れる」）。画面イラストとテキストだけ。最後にサービス名を大きく出す |
| ブランディア | 広告用 | 30〜60秒 | 詰め込みすぎず、詳細を見に行きたくなるところで止める。ターゲットに合わせて「かわいい」デザインにする |
| ビズリーチ・ダイレクト | サービス紹介 | 120秒〜 | 特徴を3つに絞り、イラスト・グラフ・テキストで順番に見せる。ブランドカラーを一貫して使う |
| タウンワークオンライン | サービス紹介 | 60〜120秒 | 前半で手順を見せ、後半でサポート体制を見せて不安を取り除く |
| 怪盗ロワイヤル10周年 | ブランディング | 60〜120秒 | 懐かしさを、水彩のにじみという質感とストーリーの両方で作る |
| Paidy | ブランディング | 30〜60秒 | ナレーションなし。ブランドカラーだけで統一し、幾何学的な図形の動きで世界観を伝える |
| wanokoto / MCCatalog+ | 情報発信 | 60〜120秒 | 冒頭で市場の数字を見せてチャンスを提示する。淡い色味で「難しそう」という印象を和らげる |

### 抽出ルール

1. 企画の前に目的を1つ決める（認知、理解、申込、ブランディングのどれか）。目的があいまいだと内容が決まらない
2. 尺が短いほど、訴求は1点に絞る（6秒なら1メッセージ、30秒なら全体像と手順）
3. 広告では、最初の5秒で「何のサービスか」を言い切る
4. 説明動画は「課題 → 解決策 → 手順 → 不安の解消」の順に組む
5. 色とトーンはブランドに統一する。そのトーンが感情を決める（淡い色は安心感、にじみは懐かしさ）
6. 詰め込まない。続きが気になるところで止め、リンク先へ誘導する

## 5. 企画チェックリスト（スキルで使う用）

- [ ] 目的は1つに決まっているか（認知・理解・申込・ブランディング）
- [ ] 形のないものを見せる必要があるか → あるならアニメ、ないなら実写も検討
- [ ] 配信先と尺は決まっているか（リール・広告・note埋め込み・LP）
- [ ] 尺に対して訴求の数は多すぎないか（6秒なら1、30秒なら全体像と手順）
- [ ] 冒頭の5秒で「何の話か」が伝わるか
- [ ] 手法は予算に合っているか（個人ならモーショングラフィックス、タイポグラフィ、インフォグラフィックを優先）
- [ ] 色とトーンはブランドと合っているか
- [ ] 最後に名前と行動（何をしてほしいか）を大きく出しているか

【転用メモ】のりこおばちゃん / AmeCan.で使う場合の初期設定案です。
- WISC解説：インフォグラフィック＋キャラクター（のりこおばちゃん）。淡い色味で「難しそう」を和らげる
- ツール・アプリ紹介：宅本便型（5秒で全体像、4ステップ、困っている状態からスッキリへ）
- 広告・告知の短尺：engage型（1点訴求＋名前を大きく）
